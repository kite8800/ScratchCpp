怎么用：粘贴 → 选「朗读」语言 → 点「识别并断句」→ 点播放。点任意句子从该句朗读；拖动 🐢 调语速；「译文」切换三态（不显示 / 当前句 / 全文）；「词汇表」显示/隐藏词条列表（默认显示）；「词汇」切换记忆模式（仅原文 / 仅译文 / 全部 / 不标注，默认全部）；「卡片」切换单词卡正面显示（仅原文 / 仅译文 / 全部 / 不标注，默认仅原文）；点头像切换音色。
单词表：在正文里按 英文|中文 写一行一个词（如 work|工作），这些行不计入句子；命中词在原文加下划线、译文加高亮，「词汇」按钮可把某一侧命中词挖空做填空记忆。
单词卡：断句后点「🃏 单词卡」翻卡背诵；点卡片/按空格翻面；点生图生成图片；点「✓ 记住了」标记该词、「✗ 没记住」跳过，两者都会切到下一张；全部记住奖 1 个胡萝卜。
