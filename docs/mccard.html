👆 点一下开启声音
怎么用：粘贴 → 选「朗读」语言 → 点「识别并断句」→ 点播放。点任意句子从该句朗读；拖动 🐢 调语速；「译文」切换三态（不显示 / 当前句 / 全文）；「词汇表」显示/隐藏词条列表（默认显示）；「词汇」切换记忆模式（全部 / 仅译文 / 仅原文）；「卡面」切换单词卡正面内容（图+词 / 仅词 / 仅图 / 图+义）；点头像切换音色。
单词表：在正文里按 英文|中文 写一行一个词（如 work|工作），这些行不计入句子；命中词在原文加下划线、译文加高亮，「词汇」按钮可把某一侧命中词挖空做填空记忆。
打单词测试：断句后点「⌨️ 打单词」进入专注模式，句子里命中词变成空格，看中文提示填英文；每空「🔤 拼读」逐字母读再读整词，「🔊 朗读整句」听语境。整卷作答、统一交卷：填完点「下一句」会闪本题答案并逐个念出（不拼读，念完再翻页，不判分），可「上一句」回改；全部填完点顶栏绿色「✓ 全部提交」一次性判分出成绩。回车 = 下一句。
